# 設計判断台帳

このディレクトリは、KUMA800で採用した技術選定と責任境界を残す場所です。

## 目的

- 会話ログや一時的なノートだけで設計理由を失わない
- 採用、保留、棄却を区別する
- 元の観測や失敗を消さず、後から判断を再検証できるようにする

## 命名

`NNNN-短い題名.ja.md`

例：`0001-KML参照リンクをシーズン1入口に採用.ja.md`

## 各判断に必要な項目

- 状態：提案／採用／保留／棄却／置換
- 対象シーズン
- 背景
- 判断
- 根拠
- 代替案
- 影響
- 不明点
- 見直し条件
