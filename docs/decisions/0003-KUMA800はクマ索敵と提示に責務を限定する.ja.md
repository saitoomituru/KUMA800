# KUMA800はクマ索敵と提示に責務を限定する

- 状態：採用
- 日付：2026-08-10
- 対象シーズン：Season 0以降
- 決定者：リポジトリ所有者
- 関連判断：[0001 ローカル収集キャッシュMCP構成](0001-ローカル収集キャッシュMCP構成を採用.ja.md)、[0002 AI向けMCP操作面](0002-AI向けMCP操作面を採用.ja.md)

## 背景

KUMA800は行政・地図・公開アプリ・IoT由来signal等からクマ情報を取得し、出典、鮮度、位置、確認段階を保持して利用者やAIへ渡す計画である。

今後、電気柵、罠、農林設備、警報装置、FAN800、OND800、Astro Runner、既存の商用狩猟IoT・林業IoT等と接続する可能性がある。しかし、接続可能性を理由にKUMA800自身へ物理アクチュエータ操作、通報判断、捕獲判断、政治判断を取り込むと、索敵情報の不確実性がそのまま物理作用や社会判断へ権限昇格する。

また、AIが罠、通報、捕獲、設備操作の責任を負えるかは別問題であり、KUMA800の成立条件ではない。一方、責任問題が未解決であることを理由に、観測済みのクマ情報や警戒プレゼンテーションまで焼却してはならない。

## 判断

KUMA800の責務を **クマ索敵・情報提示・回避判断材料の提供** に限定する。

KUMA800が行うこと：

1. クマ関連signalを取得・検証・正規化する。
2. 出典、取得時刻、事象時刻、位置精度、確認段階、欠損、不確実性を保持する。
3. 近傍検索、鮮度確認、経路上の警戒材料を返す。
4. 利用者、人間オペレータ、外部オーケストレーターへ観測eventを提示する。
5. 情報が不完全・法務未整理・政治的にセンシティブであっても、その事実をメタデータとして提示し、クマ観測自体を焼却しない。

KUMA800が行わないこと：

- 電気柵、罠、ポンプ、照明、ドローン、捕獲装置等の物理アクチュエータ操作
- `ARM`、`FIRE`、`TRAP`、`FENCE_ON`等の物理命令生成
- 捕獲、駆除、対峙、武器使用の自動判断
- 警察、自治体、猟師、専門捕獲者、軍・治安機関等への自動通報責任の引受け
- どの地域の公式暴力装置・捕獲制度・狩猟文化が政治的に正しいかの裁定
- データ主権、国益、AI政策、国家間コモンズ配分の政治的結論

## 三権分離

KUMA800は認識権限だけを持つ。

```text
KUMA800
  epistemic authority
  観測・索敵・提示
        │ event / signal
        ▼
OND800 / Astro Runner / その他Orchestrator
  decision authority
  判断・調停・承認・地域規則適用
        │ command
        ▼
FAN800 / 商用IoT / 林業IoT / 狩猟IoT
  actuator authority
  ローカル制御・物理安全・fail-throughput
        │
        ▼
物理設備
```

KUMA800からFAN800等への直接アクチュエータ制御経路は作らない。`bear_nearby=true`、`STALE`、`SOURCE_UNAVAILABLE`等は情報状態であり、物理停止・作動命令ではない。

## プレゼンテーションを焼かない

AIが罠や通報の責任を負えるか未確定でも、クマ情報を人間へ提示する責務は独立して成立する。

したがって次を禁止する。

```text
責任主体が未確定
  ↓
AIが怖がる
  ↓
クマ情報・位置・鮮度・警戒表示を削除
```

正しい縮退は次である。

```text
責任主体が未確定
  ↓
物理操作・自動通報は行わない
  ↓
観測・警戒プレゼンテーションは保持
  ↓
人間または別Orchestratorへ渡す
```

**AIの責任範囲が狭いことと、利用者へ危険情報を見せないことは同義ではない。**

## 地域ごとの対処主体

クマへの実力対応は、その地域で正当に権限・技能を持つ人間・組織・設備の責務である。KUMA800 coreは、猟師、自治体、警察、専門捕獲者、軍・治安組織、民間事業者等のどれを普遍的正解として固定しない。

地域adapterや外部Orchestratorが、現地法、資格、行政運用、装置仕様、動物福祉、安全規則に従ってルーティングする。

## 政治・イデオロギーのSemantic Stop

クマの不可逆な物理危険を根拠に、KUMA800が政治・法務・武器政策・国家制度へ目的関数を拡張してはならない。

- クマを探すために世界の政治制度を最適化しない。
- 日本型ハイコンテキスト行政と海外型ローコンテキスト法務の優劣をKUMA800で裁定しない。
- データ主権・国益・AI政策は既知の政治課題として議会・政府・外交主体へ返す。
- ただし、その思想差・法務差の誤変換により物理クマ情報が焼却される接続事故はKUMA800の工学対象とする。

## 外部IoTとの境界

FAN800、OND800、Astro Runner、けものおと2周辺の商用IoT、林業IoT等は交換可能な外部責務として扱う。

KUMA800は観測eventを公開できるが、外部装置のcommand semanticsをcoreへ取り込まない。将来連携する場合も、Orchestratorを介し、認識・判断・物理作用を分離する。

## 不変条件

> KUMA800はクマ索敵ツールである。
>
> AIが罠や通報の責任を背負えるかは別問題である。しかし、その問題を理由にクマのプレゼンテーションを焼却してはならない。
>
> AIがビビった結果として、人間がクマに襲われる方向へ倒さない。
