# note/AGENTS.md — KUMA800実験ノート規約

`note/` は、シーズン0以降の探索・観測・失敗・比較を残す実験台帳です。

## ルール

- 新規ノートはタイトル先頭を `[下書き]` とする
- 事実、観測、考察、仮説、決定、不明を分離する
- URL、取得日時、ハッシュ、使用コマンド、解析器の版を残す
- 取得成功を内容の正しさと同一視しない
- 公開データの利用条件、再配布条件、位置情報の公開境界を記録する
- 採用済み設計は `docs/decisions/` へ昇格する
- READMEへ自動昇格しない

## 推奨命名

`YYYY-MM-DD-短い題名.ja.md`

## 必須節

1. 目的
2. 入力と情報源
3. 実行環境
4. 手順
5. 観測
6. 考察
7. 不明点
8. 次の判断

新規作成時は [TEMPLATE.ja.md](TEMPLATE.ja.md) を複製してください。
